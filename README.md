# KAIG Aviary Digital Twin — ASFAN

**التوأم الرقمي لمحمية الطيور – حدائق الملك عبدالله العالمية (الرياض)**

برنامج Windows يعمل دون إنترنت: مشهد ثلاثي الأبعاد للقبة، نموذج محاكاة للمناخ والتبريد والطاقة والمياه والطيور والزوار، 10 سيناريوهات طوارئ وتدريب، وتقارير PDF.

## التحميل / Download
⬇️ **[تحميل مباشر / Direct download — KAIG-Aviary-Twin-1.0.0-Portable.exe (117 MB)](https://media.githubusercontent.com/media/asfantrading-create/KAIG-Aviary-Twin/main/KAIG-Aviary-Twin-1.0.0-Portable.exe)**

- دليل المستخدم (عربي/إنجليزي) موجود داخل البرنامج: زر القائمة ☰ ← دليل المستخدم.
- إذا ظهرت رسالة Windows SmartScreen اضغط «مزيد من المعلومات» ثم «تشغيل على أي حال».

**English:** offline Windows digital twin of the KAIG bird sanctuary dome. Download the portable EXE from the latest release and run it directly; no installation needed. The bilingual user manual opens from ☰ → User Manual. If SmartScreen appears, click “More info” → “Run anyway”.

**Requirements:** Windows 10/11 64-bit · 8 GB RAM · WebGL 2 graphics (dedicated GPU recommended).
